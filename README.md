 # Final Year Project: SatBuilder 

SatBuilder is a dedicated software application designed for modeling and configuring 1U CubeSats.\
1U Cubesats are 10 x 10 x 10cm satellites which are very cost and time efficient. They are mostly sent for research purpose in space. The most commonly used types are 3U Cubesats (10 x 10 x 30 cm). Each Cubsat has a single plate that acts as its subsystem. The most common subsystem are: Power, Communication, Structure, Payload, ADCS, Thermal control.

##  Features & Highlights
Allows user to design and create their own 1U CubeSat.\

The following structure is followed:\
1.Element - User design the element or components that will make up each subsystem of the CubeSat\
2.Board - The Elements are then placed on top of the board which represents each subsystem\
3.Stack - User stack these subsystem based on their needs and design\
4.Connectivity - User makes electric connections between each element on the board so they are able to connect with eachother. Main power comes from solar irradiance\
5.Orbit Design - User decide the type of orbit for satellite
